# Full Stack Code Review Challenge

You have received a functioning Customer Task Portal built rapidly with AI coding tools. It has not received a full production-readiness review.

**Your task (recommended timebox: 3 hours):**

1. Run the application locally and explore the key flows.
2. Review the frontend, backend and data access code.
3. Document **at least five significant issues**, ranked by severity and business impact.
4. Fix the **three most important issues** you identify.
5. Add automated tests that would fail before your fixes and pass afterward.
6. Write `REVIEW.md` explaining your findings, priorities, fixes, tests, and remaining production risks.

**AI tools are permitted and encouraged**, but you must understand and be able to defend your final changes. Do not rewrite the entire app. Preserve existing functionality. Submit a branch/PR or repository link with a clear commit history.

We will discuss your approach in a **30-minute follow-up**, including one small live change to your solution.

**Evaluation:** risk prioritization, depth of reasoning, correctness of fixes, tests, code quality, and ability to discuss trade-offs. Finding the highest number of minor issues is not the goal.
